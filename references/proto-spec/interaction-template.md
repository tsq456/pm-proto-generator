# 交互说明写法（页面规格说明内嵌）

描述本页操作的触发条件、处理结果、异常反馈和关联影响。规则见 [README.md](./README.md)；每页仍维护一个 Spec 文件。

## 推荐结构

```md
## 交互说明

### 页面加载

- **产品要求**：从指定入口进入，按默认条件加载列表；跨页传参时写明对象和默认筛选。
- **异常反馈**：加载失败显示错误提示并提供重试。
- **原型覆盖**：已演示 / 部分演示 / 未演示（按实际情况填写）。

### 筛选与重置

按“字段说明 / 筛选字段”执行查询与重置，避免重复维护字段规则。

### INT-001 新增计划

- **操作入口**：列表工具栏“新增计划”。
- **可操作条件**：具有新增权限，权限范围见“角色与权限”。
- **成功结果**：打开空白新增表单；提交校验通过后保存，关闭弹窗并刷新列表。
- **异常反馈**：字段校验失败时显示字段错误并保留输入；保存失败时提示原因，不关闭弹窗。
- **关联影响**：新增记录在列表可见；如有其他关联影响，引用对应业务规则。
- **原型覆盖**：按实际完成情况填写，未演示的异常路径单独注明。

### INT-002 启停计划

- **操作入口**：列表行内“启用 / 停用”。
- **可操作条件**：引用业务规则中的状态流转与角色权限；写清禁用或点击后拦截方式。
- **成功结果**：二次确认后切换状态并刷新当前行。
- **异常反馈**：提示原因，保持原状态。
- **关联影响**：引用启停对关联任务的业务规则；未知则进入待确认事项。
- **原型覆盖**：按实际完成情况填写。

### 关闭弹窗

取消或关闭时不保存；如存在未保存内容提醒，明确触发条件。
```

## 完整度与边界

- 保存、提交、删除、启停、审核、发布等关键操作必须写清：条件、成功、失败、关联影响。复杂操作使用短段落或列表，不使用八列交互宽表。
- 查询、重置、关闭、纯跳转可简写，不机械套用空字段。
- 跨页跳转写明目标 page-id、传递对象、目标默认条件、返回后的筛选与分页恢复方式；未知内容列入待确认事项。
- 权限在“角色与权限”集中维护，交互仅引用；业务规则引用来源章节；已有 BR 编号可沿用，不要求上游补编号。
- 按钮名称与已选定的真相源一致；产品要求与原型覆盖分开，不能以原型简化替代正式产品行为。
- ProtoMock、存储方式等实现信息集中在末尾“原型演示说明”，不夹在业务操作中。
