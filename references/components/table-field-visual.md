# 字段视觉表达（全站）

> 本文为上游未指定时的 kit 默认表现。已确认页面 Spec 的布局、列序、字段、交互与能力边界优先；不据此新增业务能力。

这是**全局规范**，不只用于列表表格。列表主表、详情 `.ob-desc`、详情内嵌子表、抽屉只读描述，同一套判定。

不要按数据类型决定怎么画。先判断字段是**普通属性**、**分类属性**还是**状态**。

> **禁止仅根据后端字段类型决定视觉表达。** `enum` 不等于 Tag，`boolean` 不等于 Switch，`status` 不等于彩色标签。展示方式优先看业务语义和用户要不要扫读。

类名落在 `kits/ob-static/components.css`。状态用 `.ob-status`，分类标签用 `.ob-tag`。

**禁止**详情页标题旁跟状态 Tag（`h1` 内不要 `.ob-tag` / `.ob-status`）。状态只出现在字段值里。

## 1. 怎么判断

```
字段是否表达当前运行、流程、完成度或生命周期？
        │
        ├─ 是 → 状态
        │       圆点 + 文字
        │
        └─ 否
            │
            ├─ 是否表达类型、分类或业务特征？
            │       ├─ 是 → 分类属性（普通文本，或统一浅色 Tag）
            │       └─ 否 → 普通属性（普通文本）
```

### 1.1 普通属性

描述对象自身的基础信息，没有明显的分类识别或状态语义。

例如：所属园区、负责人、计费方式、楼层数、建筑面积、所属部门。

默认**普通文本**。不用 Tag，不用状态圆点。

### 1.2 分类属性

回答「它是什么」「属于哪一类」「有什么业务特征」。

例如：楼栋类型、企业类型、规划用途、经营方式、任务类型、资质类型、服务类型。

默认可普通文本，也可 Tag。**低强调、普通枚举优先普通文本。** 只有需要快速区分类别、同一列类型差别明显、筛选或运营判断依赖它、并且页面密度还放得下标签时，才用 Tag。

### 1.3 状态

回答「现在怎么样」「进行到哪一步」「当前是否生效、是否完成、是否异常」。

例如：任务状态、审核状态、招商状态、启停状态、配置状态（地图框选）、生命周期状态（空置 / 出租中 / 已售卖）、执行状态、支付状态。

统一：**语义色圆点 + 状态名称**。不要默认画成彩色 Tag。

## 2. Tag

Tag 表达分类、属性、业务特征，不表达流程、启停或异常。

普通 Tag 用同一种浅色：`.ob-tag` 或 `.ob-tag--default` / `.ob-tag--info`。不要为了好看给每个枚举随机配色。

规划用途「工业用地 / 商服用地 / 其他」若要用 Tag，全部同一种浅色。

只有类别本身有**长期稳定、全系统一致**的业务语义，并且快速区分有价值时，才允许固定类别颜色。禁止「工业用地蓝、商服用地紫、其他黄」这种仅用于区分的配色。颜色一旦有业务含义，就必须是系统级规则，不能一页一个样。

## 3. 状态色

全系统只用五类，单页不得自造颜色。圆点类名：

| 语义 | 类名 | 场景 | 例子 |
| --- | --- | --- | --- |
| 灰 | `.ob-status--stopped` | 未开始、关闭、停用、失效、退出当前流程 | 空置、已售卖、已停用、未框选、禁止招商、无抵押 |
| 蓝 | `.ob-status--processing` | 正在进行、处理中 | 出租中、招商中、审批中 |
| 橙 | `.ob-status--creating` | 等待、提醒、需要关注 | 待审核、待确认、即将到期、有抵押 |
| 绿 | `.ob-status--running` 或 `--success` | 完成、正常、可用 | 已启用、已框选、允许招商、已通过 |
| 红 | `.ob-status--error` | 失败、异常、驳回、风险 | 异常、失败、已驳回、超期 |

```html
<span class="ob-status ob-status--processing"><span class="ob-status__dot"></span>出租中</span>
```

圆点固定 6×6，不随列宽被压扁（`flex: 0 0 6px`）。状态文字不换行。

颜色只是辅助，必须同时有状态文字。

**按业务语义分色，不按状态名称分色。** 「出租中」是正在进行，用蓝，不用绿。「已售卖」若表示交易完成可用绿；在资产运营里表示已退出可招商池，用灰。

## 4. 布尔

不要因为 true/false 就一律开关或 Tag。

表示对象属性（是否重点企业、是否国有企业）：写「是 / 否」，或属性型浅色 Tag。

表示当前运行或配置（是否启用、是否招商、是否完成地图框选）：按状态画圆点。

```text
● 已启用    ● 已停用
● 允许招商  ● 禁止招商
● 已框选    ● 未框选
```

## 5. 本包例子

| 字段 | 判定 | 展示 |
| --- | --- | --- |
| 规划用途、经营方式、楼栋类型 | 分类，低强调 | 普通文本 |
| 地图框选 | 配置状态 | 已框选绿、未框选灰 |
| 招商开关 | 启停状态 | 允许招商绿、禁止招商灰 |
| 状态 | 生命周期 | 空置/已售卖/停用灰，出租中/招商中蓝 |
| 所属园区、面积、负责人 | 普通属性 | 普通文本 |
