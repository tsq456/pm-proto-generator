样式评审样例

典型页 + ProtoMock 可写交互。列表请试：新建 / 删除 / 启停。

怎么标注
  1. 打开下方任一页面
  2. 点左下角「标注模式」，再点击不满意的区域
  3. 写下问题（颜色、间距、字号、控件形态、壳层等）
  4. 各页标完后点「导出标注 JSON」，把文件发我；或直接在对话里描述
